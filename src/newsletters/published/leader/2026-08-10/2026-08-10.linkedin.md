**In Issue 16 we said to keep a standing record of what your agents can reach and where they have been. We assumed you would have to build both halves. If you run Claude Code, part of one half already exists.**

From Friday August 14, auto mode becomes the default in Claude Code for Pro, Max and Team plans. Something will now decide, action by action, whether it is safe enough to take. Users can change the setting. Our expectation, not a measured one, is that most will not.

We wanted to know what that something decides against. We expected to find nothing published, and we were wrong. That is not the useful part, though. A product feature is: Claude Code can already export part of the record we told you to build, and the export is switched off.

Issue 17 of The Shift: what a published vendor threshold does, and what it leaves to you.

This week:

- OpenAI said it cannot rule out Critical cyber capability in an upcoming model, measured against a definition OpenAI says it published in advance. It did not find proof the line was crossed. It found it could no longer show the model had stayed below the line, and acted on that.
- Anthropic names what auto mode blocks, from destroying data to bypassing review on shared infrastructure, and cites an evaluation it commissioned, on its own models, of how often it misses. What none of the documents we read states is a failure rate a vendor would refuse to ship on. That one is yours to set.
- Claude Code can already export tool decisions and permission-mode changes to your security monitoring. That export is off by default, and while the switch is small, running it across a fleet is not. What the log contains is that vendor's account too, so check the stream against what you expected. The log names individual engineers, so someone has to tell them it exists and that it is not an input to performance management.

Disclosure is not mainly what closes the gap. A vendor's threshold describes what a model can do, not what it does inside your pipeline, holding your credentials, against your repositories. Those numbers were not measured on your work. What would close it is your own policy, your own record, and a number measured on your own work, and that last one cannot reliably be got yet.

If you can only start one this week, our vote is the record, and only if you run Claude Code. On other stacks it is yours to find. Not because the policy can wait, because it does not, but because a decision nobody logged is far harder to reconstruct afterwards. Then work out what your agents can reach, because that half is still yours.
