# Project Briefing

Migrated from legacy `docs/BRIEFING.md` via `/wr-retrospective:migrate-briefing` on 2026-08-07.

## Critical Points (Session-Start Surface)

- **The risk scorer is a design reviewer, not a formality.** Its STOPs have repeatedly caught genuine design defects that architect passes missed. Read a STOP as a finding, not a gate to satisfy. When its remediations would each breach a decision, look for a third close rather than choosing between them. ([risk-scorer-behaviour.md](./risk-scorer-behaviour.md))
- **Verify a ticket's own premises before acting on them, not just its prose.** Tickets carry stale claims about repo state (a governance tier said not to exist, a path pinned at a version no longer on disk). Read the file from disk. The same applies to ADR/RFC references in subagent verdicts. ([what-you-need-to-know.md](./what-you-need-to-know.md))
- **A `blob/master` link in outbound prose resolves against the REMOTE, so it 404s while your commits are unpushed.** On 2026-08-09 the external-comms gate passed a P109 upstream comment on prose, then caught this separately because it had been asked to verify claims against disk. If an iteration is barred from pushing, queue the post rather than rewording it: risk-reducing the prose cannot fix an unresolvable link. ([governance-iteration-friction-2026-08-09-p109-iter.md](./governance-iteration-friction-2026-08-09-p109-iter.md))
- **The external-comms gate cannot see a body passed with `--body-file`, and edits after a PASS invalidate the marker.** Pass the body inline as `--body "$(cat <<'EOF' ... EOF)"`, dispatch the reviewer synchronously, and do not touch a word of the draft between the PASS and the call. ([what-will-surprise-you-archive.md](./what-will-surprise-you-archive.md))
- **The session-start `git status` snapshot strips the leading space from its FIRST line only, so line 1 looks staged when it is not.** Porcelain's unstaged form is ` M path`; the snapshot renders it as `M path`. On 2026-08-09 the risk scorer read that as a staged file and returned STOP on a precondition never breached. Never infer staging from the snapshot: run `git diff --cached --name-only` and hand THAT to any agent you ask, because a read-only subagent cannot see the index at all. ([what-will-surprise-you.md](./what-will-surprise-you.md))
- **The maintainer persona is ratified as of 2026-08-09, and that unblocked executable internal-tooling work.** `docs/jtbd/internal-maintainer/` plus JTBD-400/401/402 all carry `human-oversight: confirmed`, `oversight-date: 2026-08-09`. While they were unconfirmed the JTBD edit gate withheld its marker on ISSUES FOUND, and "reasons from an unratified persona" was one an agent could not clear, so the whole class was unreachable AFK. Anchor tickets to these jobs in prose under `## Related`, never in header lines, and drop the provisional caveat. Tickets written before 2026-08-09 still carry that caveat; it is stale, not current state. ([what-you-need-to-know.md](./what-you-need-to-know.md), [governance-iteration-friction-2026-08-09-p115-iter.md](./governance-iteration-friction-2026-08-09-p115-iter.md))
- **Before building a gate in a consumer repo, check whether the upstream gate already exists and is merely scoped past this layout.** P115's root cause was exactly that: `itil-changeset-discipline.sh` is installed and running here, and its path classifier ends in `*) # Non-packages/ path: always allow`, so with no `packages/` tree every site path falls through and the hook cannot deny. Wired, ratified, and structurally unable to fire. (The structural claim is what was verified against the source; that it has in fact never fired here is an absence claim no read of disk can settle.) ([governance-iteration-friction-2026-08-09-p115-iter.md](./governance-iteration-friction-2026-08-09-p115-iter.md))
- **A bare ID of any kind is ambiguous, and Tom cannot resolve one.** `ADR-NNN` collides across this repo and upstream `agent-plugins` (both number from 001; 014, 024, 028, 032 and 036 each hit an unrelated real decision). The same holds for problem numbers, and Tom named it directly on 2026-08-09: *"you need to remember that I have many projects all with their own problem numbers"*. Never let an ID carry meaning in a reply: name the thing, every mention, including the second and third in one conversation. The citation reads plausibly and points at a document that exists, so the error is quiet. Write `upstream ADR-NNN` for cross-repo references, and prefer grounding a claim in the artefact on disk over the number. ([governance-iteration-friction-archive.md](./governance-iteration-friction-archive.md))
- **Two of run-retro's own detectors cannot run in this repo, and one fails loudly enough to look like your mistake.** There is no `packages/` tree here, so `wr-retrospective-check-readme-jtbd-currency` emits nothing at all. That silence is expected, not a broken invocation; it is ticketed as P130. ([what-you-need-to-know.md](./what-you-need-to-know.md))
- **The architect can take several rounds, and the later rounds are the valuable ones.** Treat an ISSUES FOUND as the review working, not as a formatting problem to route around; the P126 fix went ISSUES FOUND four times before passing. ([what-will-surprise-you.md](./what-will-surprise-you.md)) The two-reviewer case is separate: on 2026-08-09 the architect and the JTBD reviewer independently rejected the same defect in a first draft, and that correction became the substance of the fix. ([governance-iteration-friction-2026-08-09-p109-iter.md](./governance-iteration-friction-2026-08-09-p109-iter.md))
- **A genuine PASS can still leave the edit blocked at any of six gates, and the cause is never the verdict string.** Confirmed against the installed hooks on 2026-08-09 (P124). Every governance marker is written by a `PostToolUse` hook matching the literal string `Agent`: architect, jtbd, risk-score, voice-tone, external-comms, style-guide. Neither a `SendMessage` resume nor a background-launched reviewer fires any of them, so dispatch a FRESH, SYNCHRONOUS `Agent` spawn. On `wr-architect` 0.20.0, which is what this repo runs, the mark hook routes an unparseable verdict into the same allow-with-marker branch as PASS, so asking for the literal `**Architecture Review: PASS**` is belt-and-braces rather than load-bearing, and a "no marker found" block after a genuine PASS means the marker landed under a session ID the gate does not read (P088). Only wr-architect names the resume trap, in one deny string; external-comms names the background half only; the remaining four gates block with no dispatch-shape hint at all. The six-way uniformity holds at the versions this repo pins and is already breaking upstream, so re-verify before relying on it. ([what-will-surprise-you.md](./what-will-surprise-you.md), [governance-iteration-friction-archive.md](./governance-iteration-friction-archive.md))
- **Ask the risk scorer to verify an artefact's own claims against disk, not just to score it.** One sentence in the prompt; it has caught wrong shim counts, self-contradicting figures, and two false premises it was handed. ([governance-iteration-friction-archive.md](./governance-iteration-friction-archive.md))
