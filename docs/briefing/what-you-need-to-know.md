- **The story-map gate now hard-refuses in this repo, and it is not the RFC-trace failure older notes describe.** `wr-itil-check-fix-rfc-trace` used to ask for an RFC; on the version this repo runs it asks for a release row on a story map, and because `docs/story-maps/` does not exist it exits **3** rather than reporting an untraced problem. Exit 3 means the predicate refuses to answer, not that your ticket failed a check, and its own directive says to record one item for the maintainer and carry on rather than stopping. The local precedent set when P070 closed still applies and was applied again on 2026-08-23 for P141: when the fix's design already lives in a decision record, land it and record the gate decision in the ticket, rather than bootstrapping a whole tier for one small edit. Do not read exit 3 as a blocker. One thing the exit-3 path hides: the predicate answers from a union of two tiers and scans `docs/rfcs/` FIRST, so a problem an RFC already traces exits 0 before the map count is ever consulted. This repo has an RFC tier, so expect either outcome depending on the ticket.
