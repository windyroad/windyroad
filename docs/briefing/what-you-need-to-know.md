- **"The fix site is upstream" stopped being a reason to park on 2026-08-08.** ADR-048 amends ADR-036: an upstream pull request raised from the working clone is the default outbound artefact, a park is a staging state rather than a terminal one, and the un-park trigger set gains "the pull request merges". Its three carve-outs are narrow: the upstream does not accept contributions, the design call is genuinely someone else's, or the ticket is security-classified. Filing better issues and waiting is the alternative JTBD-402 names and rejects, and ADR-036 records that it is what produced a parked backlog at 94 percent upstream-blocked. The trap it closes is that three directories look alike and only one is uneditable: the plugin cache under `~/.claude/plugins/cache/` is the read-only copy that actually runs, `~/.claude/plugins/marketplaces/windyroad` is a real clone that `/plugin marketplace update` pulls so working there breaks plugin resolution machine-wide, and `~/Projects/agent-plugins` is an ordinary working clone on the same remote and the tree to contribute from. On 2026-08-29 a P132 iteration opened on the pre-ADR-048 premise that no fix was possible and needed both the architect and the JTBD reviewer to correct it, independently, which is the convergence signal rather than two opinions. Read this before proposing a park or a second round of issue evidence.

- **A read-only reviewer cannot see the git index, so hand it the index yourself.** The risk scorer holds only Read and Glob; the architect holds Read, Glob and Grep; neither can run a git command, and the session-start `git status` block they would otherwise reason from lost the leading space on its FIRST line, once, rendering an unstaged file as staged. That is one observation, not a reproducible-on-demand defect: the block is injected at session start, so a session that opens on a clean tree cannot exercise it. The two on-demand skills already cover this: `/wr-architect:review-design` and `/wr-jtbd:review-jobs` run `git diff --cached --stat` and `--name-only` in the skill body before dispatching. What is uncovered is the ad-hoc dispatch, where you hand-write a reviewer prompt yourself and no skill body has run the git command first. That is the shape that produced a confident STOP on a file nobody had staged. Paste `git diff --cached --name-only` into the prompt and say the snapshot must not be used for staging inference. Ticketed as P134, whose fix site is upstream in two plugin prompts.
