## What Will Surprise You

> Older entries rotate to [`what-will-surprise-you-archive.md`](what-will-surprise-you-archive.md) under the Tier 3 budget; nothing has ever been deleted. Rotation here is by signal rather than age. The archive tail is deliberately NOT split further even though it is past the 2x must-split ratio: nothing loads an archive at session start, so another generation behind the `-archive-early` siblings would be churn. That decision and its measurements are recorded on P150; do not re-litigate it from the byte counts alone. Most recent pass: 2026-08-29 (P158 iter), which added the detector entry below, then rotated the external-comms `--body-file` entry out when the addition plus a header correction took the file over the ceiling.

- **Two reviewers converging independently is the strongest signal this stack produces, and it means stop, not iterate.** On 2026-08-23 the architect and the JTBD reviewer, given different prompts and reading different corpora, independently killed the same drafted `.github/dependabot.yml`: the architect on the ground that it reinstated a bot authoring path whose acceptance died with a supersession, the JTBD reviewer on the ground that it routed a code-quality judgement to a persona whose file explicitly excludes it. Neither had seen the other's verdict. When that happens the answer is not a better version of the artefact, it is that the artefact is the wrong shape. Dropping it and recording the open question took one round; arguing with either reviewer alone would have taken several and landed the same place. Third observation of this pattern, after the 2026-08-09 P109 iteration and the 2026-08-23 P141 iteration. **A fourth on 2026-08-23 extends it to three reviewers and to a case where the artefact was right and one line of it was wrong**: on the P154 fix the architect, the JTBD reviewer and the voice reviewer each independently found that a new lint check stripped every parenthesised span while its own header claimed it stripped only link URLs. None had seen the others. So convergence does not always mean stop; it means the finding is real and the only question left is which surface moves. There the code moved to match the header, because the header was describing the behaviour anyone would want.

- **`wr-retrospective-check-briefing-budgets` printing nothing while seven briefing files sit at or over its threshold is correct behaviour, not a silently-degraded gate.** Measured 2026-08-29: seven files under `docs/briefing/` are at or over the 5120-byte ceiling, six of them archives and the seventh `README.md`, which is over it several times across. The detector emits zero lines. Sizes are deliberately not quoted here: three successive attempts to state them were falsified by the very edits that carried them, including edits to this entry. Run `wc -c docs/briefing/*.md` if you need the numbers. Reading that as a defect is the natural move and it is wrong. The script excludes `README.md` because it is the Tier 2 index rather than a Tier 3 topic file, and excludes every `*-archive*.md` because archives are rotation sinks that nothing loads at session start, which upstream P322 closed after the forced-choice it created. Every remaining topic file genuinely is under the ceiling. The largest live topic files after this session's rotations sit between roughly 4.6 and 4.9 KB, so the margin is thin and the detector is worth re-running rather than assumed. The trap is sharper here than elsewhere because this repo carries a live ticket class for governance surfaces that degrade silently to a clean-looking run, so an agent arrives primed to file exactly this false positive. Read the script's header before ticketing an empty result from it; the exclusions are documented there.
