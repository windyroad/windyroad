- **Two reviewers converging independently is the strongest signal this stack produces, and it means stop, not iterate.** On 2026-08-23 the architect and the JTBD reviewer, given different prompts and reading different corpora, independently killed the same drafted `.github/dependabot.yml`: the architect on the ground that it reinstated a bot authoring path whose acceptance died with a supersession, the JTBD reviewer on the ground that it routed a code-quality judgement to a persona whose file explicitly excludes it. Neither had seen the other's verdict. When that happens the answer is not a better version of the artefact, it is that the artefact is the wrong shape. Dropping it and recording the open question took one round; arguing with either reviewer alone would have taken several and landed the same place. Third observation of this pattern, after the 2026-08-09 P109 iteration and the 2026-08-23 P141 iteration. **A fourth on 2026-08-23 extends it to three reviewers and to a case where the artefact was right and one line of it was wrong**: on the P154 fix the architect, the JTBD reviewer and the voice reviewer each independently found that a new lint check stripped every parenthesised span while its own header claimed it stripped only link URLs. None had seen the others. So convergence does not always mean stop; it means the finding is real and the only question left is which surface moves. There the code moved to match the header, because the header was describing the behaviour anyone would want.
